# Geethika — Portfolio 3.0

A cinematic, responsive, interactive portfolio with **no build step**. Created for VS Code Live Server.

## Run in VS Code
1. Extract the ZIP and open the **Geethika_Portfolio_3_0** folder in VS Code.
2. Install **Live Server** by Ritwick Dey (if needed).
3. Right-click `index.html` → **Open with Live Server**, or use **Go Live**.
4. The site will open in your browser, usually at `http://127.0.0.1:5500/`.

You can also open `index.html` directly, but Live Server is recommended.

## Features
- Cinematic portrait hero with 3D mouse movement and scroll reveals
- Actual uploaded self-supervised LSTM forecasting screenshots: stable, complex and Flask app
- Actual uploaded federated learning results and architecture diagram
- Clickable full-screen image gallery (also closes via Escape)
- Dayora interactive conceptual phone preview, clearly labelled as conceptual
- Internship timeline, skills, education, certification and contacts
- Responsive layout, keyboard-operable controls and reduced-motion support

## Publish
Create a GitHub repository, upload the **contents** of this folder to its root, then enable GitHub Pages in repository Settings → Pages. This site uses relative file paths and works from a repository subpath.
